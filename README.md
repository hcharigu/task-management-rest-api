# Task Management REST API

Simple REST API for task management, built with Java 17, Spring Boot and Maven.

## Functional scope

The API must support:

- Create tasks.
- List tasks.
- Retrieve a task by ID.
- Update tasks.
- Delete tasks.
- Mark tasks as completed.

## Technical requirements

- Java 17.
- Spring Boot.
- Maven.
- Local persistence.
- Input validation.
- Controlled error handling.
- Automated tests.
- API documentation.
- Local build and execution instructions.

## Restrictions

- Keep the solution simple and locally executable.
- Do not add authentication or authorization.
- Do not add frontend components.
- Do not add messaging.
- Do not add Docker.
- Do not add cloud services.
- Do not add external integrations.
